El cliente HTTP que usan tú y tu agente de IA

Un binario. Sin cuenta. Sin telemetría. Una app de escritorio tipo Postman con servidor MCP integrado: tu agente ejecuta tus peticiones guardadas con respuestas compactas y los secretos tapados, y tú ves cada llamada en vivo y apruebas las delicadas.

Por qué RunPost

MCP integrado

13 tools compactas. El agente usa tus peticiones guardadas por nombre en vez de reescribir URL, cabeceras y tokens; select, rangos y diffs mantienen pequeñas las respuestas.

Panel Agente en vivo

Cada llamada del modelo como una fila —tool, petición, estado, ms, bytes crudos → enviados— con medidor de tokens.

Guardarraíles

Por colección: métodos permitidos, aprobación en la app (Aprobar / Denegar, 60 s) y límite por minuto.

Secretos fuera de los archivos

Tapados para el agente, el historial y los logs, y si quieres en el llavero del sistema en lugar del workspace.

Costumbres de Postman

Colecciones, entornos, scripts (pm.*), Collection Runner, importar/exportar v2.1 y los mismos atajos.

Local y amigable con Git

Un binario, sin cuenta, sin telemetría. Un JSON por colección y por entorno.

Instalar

Los binarios aún no están firmados, así que el primer arranque pide confirmación. Cada bloque termina dejando runpost_mcp (CLI y servidor MCP) en el PATH.

Windows

Invoke-WebRequest https://github.com/paul0610/runpost/releases/download/v0.2.0/RunPost_0.2.0_x64-setup.exe -OutFile RunPost-setup.exe
.\RunPost-setup.exe
[Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path','User') + ";$env:LOCALAPPDATA\RunPost", 'User')

macOS (Apple silicon)

curl -LO https://github.com/paul0610/runpost/releases/download/v0.2.0/RunPost_0.2.0_aarch64.dmg
hdiutil attach RunPost_0.2.0_aarch64.dmg && cp -R /Volumes/RunPost/RunPost.app /Applications/ && hdiutil detach /Volumes/RunPost
xattr -dr com.apple.quarantine /Applications/RunPost.app && sudo ln -sf /Applications/RunPost.app/Contents/MacOS/runpost_mcp /usr/local/bin/runpost_mcp

Linux (Debian / Ubuntu; también AppImage)

curl -LO https://github.com/paul0610/runpost/releases/download/v0.2.0/RunPost_0.2.0_amd64.deb
sudo apt install ./RunPost_0.2.0_amd64.deb
runpost_app

Conectar tu agente

Claude Code (2.1.275 o posterior), una línea en la terminal:

claude plugin install runpost --marketplace paul0610/runpost

O dentro de Claude Code: /plugin marketplace add paul0610/runpost y después /plugin install runpost@runpost.

El plugin trae el servidor MCP, la skill api-testing y los comandos /runpost:run, /runpost:suite y /runpost:import. Con la app abierta sobre el mismo workspace, sus llamadas aparecen en el panel Agente y las peticiones protegidas esperan tu aprobación.

Codex, Claude Desktop y otros: en la app, Agente → Conectar agente ▾ copia la configuración con tus rutas. Ejemplos y un AGENTS.md para Codex en docs/mcp-client-configs.

Tools MCP

Las mismas por stdio y por Streamable HTTP (http://127.0.0.1:7879/mcp con la app abierta). Contrato completo: docs/MCP.md.

ToolQué hace
ws_overviewColecciones, entornos y el activo. La primera llamada.
list_requests · searchBusca peticiones guardadas por colección, carpeta o texto.
get_requestUna petición guardada, solo los campos pedidos.
run_requestEjecuta una petición guardada: estado, ms, cuerpo minificado y truncado, select (JSONPath).
sendUna petición suelta con {{variables}}; se puede guardar.
get_responseLee una respuesta anterior por rangos, o diff_against otra o una referencia guardada.
run_collectionEjecuta una colección o carpeta con sus scripts: resumen o solo fallos.
env_get · env_setVariables (secretos como ***; los secretos van al llavero del sistema).
upsert_request · import_postmanCrea colecciones en una llamada o importa Postman v2.1.
historyEjecuciones recientes con las URL enmascaradas.
